# Gerador de Prompt

Gerador universal de prompts (vídeo/imagem) com GUI em Tkinter. Sem dependências externas.

## Instalar (Windows)
Requer Python 3.9+ com Tkinter (já vem no instalador oficial do python.org).

```
cd %USERPROFILE%\Desktop
git clone -b claude/prompt-generator-gui-ir1a57 https://github.com/teste0102/gerador-de-prompt
cd gerador-de-prompt
executar.bat
```

Ou rode direto: `python gerador_de_prompt.py`

Opcional (tradução online): `pip install deep-translator`
